# 系统加入申请

在「所有系统」中点击「申请加入」，默认选中「系统管理员」，并自动生成链接。链接包含申请人的姓名、`ystId`、系统名称、中文名和角色，收件人登录后可直接打开详情页，查看这些信息。切换角色会立即更新链接。弹窗中的负责人姓名是会话入口。会话接入后，用户可复制链接，点击负责人并在对话窗口中粘贴发送。

通过链接打开一个尚未加入的系统时，可在「无系统访问权限」页直接点击「申请加入」，使用同一个申请弹窗。

链接不依赖本地存储，可以跨设备转发。任何持有链接的已登录用户都能查看其中的字段，只应分享给相关人员。详情页只展示链接里的内容，生成和查看链接均不会提交审批或授予访问权限。

详情页突出系统名称，申请人和角色在宽屏并排、窄屏纵向排列。点击「通过申请」仅提示审批尚未接入，不修改成员关系；链接无效时该按钮禁用。

系统中文名通过申请链接一同传递，在详情卡片的系统标识下方展示；旧链接未包含中文名时仍可正常查看，不显示空白占位。
